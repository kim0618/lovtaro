## 패턴별 결론 (2026-06-21)

- **상황한정+선택유도** ("~기준으로, 하나만 골라보세요"): 최강 (25k·22k·6.7k·3.9k·2.7k). 브레이크아웃 공식. 매주 1~2회 보장. 단 "하루에도 몇 번씩 생각나는 사람"은 2.7k로 상한 24k 대비 낮음 → **선택유도여도 상황한정 문구가 약하면(추상적 빈도) 도달 절반 이하**. "자꾸 떠오르는/지금 마음에 두고 있는" 같은 강한 한정구 우선.
- **시점+변화동사** ("다음 주, ~달라질까요"): 가장 안정 (Sunday 평균 3~8k). 변동 작음.
- **위치메타포** ("어디쯤·거리·온도·기울다"): 강하나 변동 큼 (862~8.9k). "이 관계 지금 어디쯤"(862)·"몇 순위쯤"(846)처럼 **상황한정 없이 위치어만 쓰면 추락**.
- **양자택일** ("X일까 Y일까"): 편차 극심 (468~10,000). 단어 페어 강도 + 비주얼 시너지 필수. "미련일까 미안함일까"(716)·Empress 468 = 약한 페어/비주얼 시너지 부재 시 추락.
- **소개형/카드명형(수·금 + 메이저 reveal)**: 전멸 (178~1,101, 중앙값 ~600). **슬롯 가치 최하**. 폐기/대체 검토 1순위.
- **상대행동+내해석**: 편차 큼 (423~1,692). "조용했던 사람이 왜 갑자기 먼저 다가올까"(1,692)는 상승, "다 맞춰주는 사람인데 왜 나한테는 자꾸 늦을까"(467)는 추락 → **반전 행동(조용→다가옴, 차분→진심)** 이 있어야 후킹.
- **추상어·yes/no** ("운명·신호·존재·좋아하고 있을까"): 전멸 (217~785). 금지.
