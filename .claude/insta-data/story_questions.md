# LOVTARO 스토리 질문 풀 & 사용 관리 (story_questions)

> 심리테스트 홍보 스토리(평일 5개) 질문 로테이션 관리. `generate-story-tests.mjs` 가 Read/Update.
> 형식: `- [ ] {slug} :: {1줄} / {2줄}` (미사용) / `- [x] {slug} (YYYY-MM-DD) :: ...` (사용)
> 한 테스트의 5개를 다 쓰면 스크립트가 자동으로 전부 미사용으로 리셋(새 사이클).
