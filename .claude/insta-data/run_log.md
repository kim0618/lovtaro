# LOVTARO /insta 실행 대장 (run_log)

> **git 동기화 파일**. PC를 두 대 이상 쓰기 때문에 존재한다.
> `content-output/`은 gitignore라 다른 PC에서 만든 결과물이 안 보이고, `~/skill-log.json`(PostToolUse 훅)은 홈 디렉토리라 역시 PC 간 공유가 안 된다.
> 그래서 **"어느 주차를 실제로 생성했는가"의 유일한 크로스 PC 근거가 이 파일이다.**
>
> - `/insta` 시작 시 **반드시 Read** + `git log --oneline -5 -- .claude/insta-data/`로 원격 대조. 생성하려는 날짜 범위가 이미 아래에 있으면 **중복 생성 금지**, 사용자에게 확인부터 받는다.
> - `/insta` 종료 시 **반드시 아래 표에 행 추가 후 사용자에게 커밋 요청**. 커밋되지 않으면 다른 PC에서 이 주차가 없는 것으로 보인다.
> - 훅(`~/skill-log.json`)은 스킬 호출만 기록하므로 **생성 여부의 근거가 아니다**(호출 후 중단해도 기록됨). 판단은 이 파일로 한다.

## 기록 형식

`| 주차(생성 범위) | 실행일 | PC | 생성 슬롯 | 영상 | 비고 |`

- **PC**: `main` / `sub` 등 구분자. 모르면 `?`
- **생성 슬롯**: 요일별 무엇을 만들었는지 압축 (예: `수 소개형·목 참여형·토 캐러셀+릴스·일 Sunday`)
- **영상**: `insta reel` / `youtube` 생성 여부
- **비고**: 미발행·재활용·부분 생성 등
