## ⚠️ 영상 URL 관련 주의

- 모든 릴스의 `video_versions` mp4 URL을 페이지에 내장된 JSON에서 찾았습니다. 해상도는 모두 720x1280입니다.
- 브라우저 도구가 쿼리스트링(서명값 `?efg=…&oh=…&oe=…`)이 붙은 출력을 보안상 자동으로 가립니다. 그래서 videos.txt에는 **서명 파라미터를 뺀 기본 경로**만 들어 있습니다. 이 경로만으로는 403이 나올 가능성이 큽니다. 서명 URL도 어차피 몇 시간~며칠이면 만료됩니다.
- **권장 다운로드 방법**: 아래 릴스 URL을 그대로 쓰세요.
  `yt-dlp --cookies-from-browser chrome "https://www.instagram.com/reel/<code>/"`
- 재생수는 그리드에 표시된 반올림값(예: 128.9만)으로 해당 릴스를 찾은 뒤, 요청서에 적힌 정확한 값을 그대로 옮겼습니다. 페이지 JSON에는 play_count가 나오지 않았습니다.
- 좋아요/댓글 수는 페이지 JSON(`like_count`, `comment_count`) 값입니다. "좋아요 숨김"으로 표시된 계정은 like_count를 신뢰할 수 없어(값 3으로 나옴) 숨김으로 적었습니다.
