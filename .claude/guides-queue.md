# Lovtaro 가이드 주제 큐

`/lovtaro-guide` 실행 시 **이 파일 맨 위에서부터** 주제를 꺼내 쓴다.
발행 완료한 행은 `- [x]` 체크 + 실제 slug/발행일 기재.

## 운영 원칙

- 매일 1편 발행 (하드 캡)
- 큐 소진 전에 다음 분 주제를 미리 채워둔다 (주 1회 토요일 권장)
- 우선순위: 카드 해석 > 상황별 가이드 > 방법론 > FAQ
- 연애 빈출 카드를 초반 2주에 몰아 SEO 노출 빠르게 확보
- 주제 변경 자유. 그날 영감에 맞춰 큐 순서 바꿔도 OK
- **큐 보충(재정렬) 절차** (2026-06-01 확정): 네이버 노출 데이터는 GA4/구글 서치콘솔에 안 잡혀 자동 조회 불가. API 연동도 안 함(수동 유지 결정). 큐가 거의 소진되면 **사용자에게 네이버 서치어드바이저 "검색 키워드/웹문서 TOP30" 화면을 요청**해서, 노출 큰 미발행 카드 순으로 다음 큐를 짠다. 보조로 GA4 네이버 랜딩 페이지(m.search.naver.com)도 참고 가능. **큐를 재정렬할 때마다 아래 "네이버 서치어드바이저 갱신 이력" 표 맨 위에 한 줄 추가(누적, 덮어쓰지 말 것).**
