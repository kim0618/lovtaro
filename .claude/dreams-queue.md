# Lovtaro 꿈해몽 사전 주제 큐

`/lovtaro-dream` 실행 시 **이 파일 맨 위에서부터** 주제를 꺼내 쓴다.
발행 완료한 행은 `- [x]` 체크 + 실제 slug/발행일 기재.

## 운영 원칙

- **주 4편 신규 - 화·수·금·토만 (하드 캡, 2026-09-15 변경, 시작 2026-09-16 수).** 이전 "매일 1편"(원래 "매일 2편")은 폐기. **월·목·일은 손질 슬롯**: ①노출 큰 저CTR 글의 title·description(kiss 5864노출/0.7% → breakup 4478/0.6 → crush 4687/0.7 순, 메타 변경 4주 쿨다운, **미착수**) ②T 미달 옛 글 보강(ex-lover 2026-09-17 완료, **잔여 pregnancy 1,388자·meal-dream 2,399자**). 밀린 편수 몰아쓰기 금지.
  - **배경**: 9/7 캡처까지 3회 연속 "신규 갭 0". 연애 직결 1군은 소진됐고, 자체 선정으로 매일 1편을 짜내자 turtle(9/15) 골격 복제·근거 부풀림 사고가 났다. 남은 수요는 범용 대형 키워드(떨어지는·죽은 사람·귀신 꿈 등)라 "표준 해몽 메인 + 연애 보조" 구조로 쓰되, **수요 실측이 있는 주제만** 발행한다.
- **🛑 수요 게이트 (2026-09-15 신설)**: 발행 전 네이버 자동완성으로 실측한다. 서치어드바이저 TOP30은 이미 쓴 글만 보여주므로 신규 발굴에는 못 쓴다.
  ```bash
  ac(){ curl -sG "https://ac.search.naver.com/nx/ac" --data-urlencode "q=$1" -d "con=1&frm=nv&ans=2&r_format=json&r_enc=UTF-8&r_unicode=0&t_koreng=1&run=2&rev=4&q_enc=UTF-8&st=100" -A "Mozilla/5.0" | python3 -c "import sys,json;print(' / '.join(x[0] for x in json.load(sys.stdin)['items'][0]))"; }
  ac "떨어지는 꿈"   # ① 변형 프로브: '꿈' 포함 변형 수(꾸미기·꿈틀·꿈수 제외)
  ac "떨어지는"      # ② 어근 프로브: 'X 꿈'이 몇 번째로 뜨나(그 단어가 꿈 검색을 얼마나 지배하나)
  ```
  통과 기준: 범용 후보는 ①≥4 **또는** ②5위 안. 연애 직결 후보는 ①≥2(대조군 "전애인 꿈"이 사이트 최상위 키워드인데 변형 3개뿐이라, 연애 직결은 변형 수가 낮게 나온다). 둘 다 미달이면 보류. 통과해도 **상위·하위 개념 점검**(slug 목록 + 기존 갈래 라벨 grep)을 별도로 거친다 - 자동완성은 수요만 말하지 겹침은 말하지 않는다.
  - 대조군 실측(9/15): 이빨 빠지는 꿈 10변형·거북이 10·키스 8·여우 4·전애인 3·옛친구 2. 변형 수는 그 명사의 일반 인기라서 연애 의도와는 무관하다.
- 우선순위: **연애 직결도 순.** 연애가 지배적 해석인 꿈을 먼저, 범용 상징 꿈은 후순위.
- **포지셔닝**: 범용 꿈해몽 사이트와 정면 경쟁하지 않는다. "연애+꿈 롱테일"(전 애인 꿈 재회, 좋아하는 사람 꿈 의미)이 우리 니치. 운세 사이트가 약하고 연애 타로 브랜드가 강한 각도를 노린다.
- **근거 위 재해석**: 전통 해몽(통념)을 베이스로 깔고 → 러브타로 연애 각도를 얹고 → 가능성의 언어로. 멋대로 발명 금지. 외부에 확립된 해석은 확인하고 쓴다.
- **큐 보충(전환) 절차**: 초기 1~3주는 아래 부트스트랩 큐(연애 직결도 순)를 소진. 데이터가 쌓이면(3주차~) 가이드와 동일하게 **네이버 서치어드바이저 "검색 키워드/웹문서 TOP30" 노출 역산**으로 재정렬. 우리 `/dream/*`가 받는 노출 큰 미발행 꿈부터 끌어올린다. 큐 거의 소진되면 사용자에게 네이버 화면 요청. **재정렬할 때마다 갱신 이력은 `guides-queue.md`의 "📌 네이버 서치어드바이저 갱신 이력" 표에 한 줄 추가(lovtaro 공통 로그, 누적)** - 꿈해몽 단독 정렬이면 큐 변경 요약에 "(꿈해몽)" 명시.
