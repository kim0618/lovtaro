# Lovtaro 꿈해몽 사전 주제 큐

`/lovtaro-dream` 실행 시 **이 파일 맨 위에서부터** 주제를 꺼내 쓴다.
발행 완료한 행은 `- [x]` 체크 + 실제 slug/발행일 기재.

## 운영 원칙

- **매일 2편 발행 (하드 캡).** 미달이면 채우려고 얇게 쓰지 말 것. 2편 중 1편만 나와도 OK.
- 우선순위: **연애 직결도 순.** 연애가 지배적 해석인 꿈을 먼저, 범용 상징 꿈은 후순위.
- **포지셔닝**: 범용 꿈해몽 사이트와 정면 경쟁하지 않는다. "연애+꿈 롱테일"(전 애인 꿈 재회, 좋아하는 사람 꿈 의미)이 우리 니치. 운세 사이트가 약하고 연애 타로 브랜드가 강한 각도를 노린다.
- **근거 위 재해석**: 전통 해몽(통념)을 베이스로 깔고 → 러브타로 연애 각도를 얹고 → 가능성의 언어로. 멋대로 발명 금지. 외부에 확립된 해석은 확인하고 쓴다.
- **큐 보충(전환) 절차**: 초기 1~3주는 아래 부트스트랩 큐(연애 직결도 순)를 소진. 데이터가 쌓이면(3주차~) 가이드와 동일하게 **네이버 서치어드바이저 "검색 키워드/웹문서 TOP30" 노출 역산**으로 재정렬. 우리 `/dream/*`가 받는 노출 큰 미발행 꿈부터 끌어올린다. 큐 거의 소진되면 사용자에게 네이버 화면 요청. **재정렬할 때마다 갱신 이력은 `guides-queue.md`의 "📌 네이버 서치어드바이저 갱신 이력" 표에 한 줄 추가(lovtaro 공통 로그, 누적)** - 꿈해몽 단독 정렬이면 큐 변경 요약에 "(꿈해몽)" 명시.
